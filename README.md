# IoT-Based Smart Lock Door System Using Raspberry Pi and RFID

## 📌 Overview

An IoT-based smart lock door system developed using Raspberry Pi and RFID technology for secure access authentication.

The system verifies an RFID card and controls the door-locking mechanism based on whether the card is authorized.

## 🎯 Objectives

* Provide secure door access using RFID.
* Authenticate authorized RFID cards.
* Control the door-locking mechanism.
* Demonstrate hardware-software integration.
* Develop an IoT-based security system.

## 🔧 Components Used

* Raspberry Pi
* RFID Module
* RFID Cards/Tags
* Door Locking Mechanism
* Power Supply

## 💻 Technologies

* Raspberry Pi
* RFID
* IoT
* Authentication
* Hardware-Software Integration

## ⚙️ Working

1. The RFID module reads the card or tag.
2. The Raspberry Pi receives the RFID information.
3. The system checks whether the RFID card is authorized.
4. If authorized, the door-locking mechanism is controlled to allow access.
5. Unauthorized cards are denied access.

## ✨ Key Features

* RFID-based authentication

* Raspberry Pi-based control
* Automated door locking
